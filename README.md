# Gene Expression Analysis of Colorectal Cancer Progression

## Project goal

This project was built as a self-directed summer coding project to learn 
practical bioinformatics and statistics in R. The goal was to replicate the
core differential expression analysis from a published colorectal cancer study 
using the same public dataset, then apply the same skills to a dataset of my 
own choosing (Part 2 to follow).


## Part 1: Paper Replication

Replicating the core method from:

Kim SK, Kim SY, Kim JH, Roh SA, Cho DH, Kim YS, Kim JC (2014), 
"A nineteen gene-based risk score classifier predicts prognosis of 
colorectal cancer patients," Molecular Oncology, 8(8):1653-1666.

DOI: 10.1016/j.molonc.2014.06.016 | PMID: 25049118

**Dataset**: E-GEOD-50760 (GEO accession: GSE50760) - 54 RNA-seq samples from 
18 colorectal cancer patients: 19 normal colon, 18 primary tumour and 
17 liver metastasis samples. Confirmed directly from the paper's 
Methods section (2.3): "The data set generated by RNA-seq is available 
in the NCBI Gene Expression Omnibus public database under the data 
series accession number GSE50760."


### What I did

1. **Downloaded and checked the dataset** (`scripts/02_Load_Data.R`) - 
   pulled the dataset directly into R using the ExpressionAtlas package and 
   confirmed sample counts matched the paper's design.
2. **Ran differential expression analysis** (`scripts/03_Differential_Expression.R`) 
   - used DESeq2 to compare gene expression between primary tumour and 
   normal tissue, filtered to 1,589 significant genes (P < 0.001, at least 
   2-fold change - matching the paper's own thresholds).
3. **Visualised the results** - a volcano plot and a heatmap of the top 
   20 significant genes (`output/volcano_plot_tumour_vs_normal.png`, 
   `output/heatmap_top20_tumour_vs_normal.png`).
4. **Compared results to the paper** - see below.
5. **Checked for survival data** (`scripts/04_survival_analysis.R`) - 
   confirmed this dataset does not support a survival analysis (see 
   Methodology notes).


### Results

My top genes by significance (COL11A1, ADAM12, CEMIP, MMP1, INHBA, FAP) 
are all well-established markers of tumour invasion and tissue 
remodelling, consistent with the biology described in the paper.

The paper highlighted **TREM1** and **CTGF** as key regulators activated 
during colorectal cancer tumorigenesis. In my own analysis:
- **TREM1** appeared strongly in my significant gene list 
  (log2 fold change = 3.4, adjusted p-value = 1.3e-09), directly 
  confirming the paper's finding.
- **CTGF** did not appear in my strict significant gene list. This 
  matches the paper's own observation that CTGF's raw expression was 
  not significantly different between groups (P = 0.17). The paper 
  identified CTGF through a separate upstream regulator/pathway analysis 
  (Ingenuity Pathway Analysis) which is outside the scope of this 
  replication.

Full significant gene list: `output/significant_genes_tumour_vs_normal.csv`


### Methodology notes

- **Differential expression tool:** The original paper used EdgeR. I 
  used DESeq2 instead - a comparable, widely-used alternative applying 
  a similar underlying statistical model (negative binomial 
  distribution). I chose DESeq2 as part of my learning goal since it's 
  a more commonly taught tool with strong documentation for beginners.
- **Dataset accession format:** The paper cites this dataset as GSE50760 
  (GEO format). I used the equivalent ArrayExpress-format ID, 
  E-GEOD-50760, since that's what the ExpressionAtlas R package requires 
  to download it - same underlying dataset but a different naming system.
- **Scope:** I replicated the core differential expression comparison 
  (primary tumour vs normal). I did not replicate the full multi-cohort 
  risk score classifier (the paper's TCA66/19-gene signature work) which was 
  developed and validated across four additional independent cohorts 
  (over 1,000 patients combined) - a scale of validation beyond what's 
  realistic for a solo summer project.
- **Survival analysis:** This dataset (the AMC cohort) does not include 
  patient survival/follow-up data. This is consistent with the paper's 
  own design - the AMC cohort was used specifically for the differential 
  expression analysis, while the paper's survival work used 4 separate external 
  cohorts. I confirmed this directly rather than attempting to force an 
  analysis the data doesn't support.


### Reflections

This was actually my first hands-on RNA-seq analysis and my first time working 
with real public genomics data than a cleaned teaching dataset.
Some things I learnt along the way:

- **Working with real, messy data:** The dataset uses different naming 
  conventions than I expected (e.g. American spelling, GEO vs ArrayExpress 
  formats) which taught me to check labels carefully rather than assume 
  consistency across databases.
- **Statistical significance isn't the only evidence:** CTGF's absence from my 
  differential expression results (although being highlighted in the paper) 
  taught me that a gene can biologically be important through pathway/regulatory
  analysis without necessarily showing up as differentially expressed on its own.
- **Debugging was more significant than expected:** A big part of this project 
  was working through practical issues e.g. restarted R sessions losing unsaved 
  work, mismatched object names, an interactive console prompt making the next 
  several lines of codes impractical etc. This taught me the value of always 
  saving code into scripts before running it and also running code in small 
  chunks I can check back on rather than big chunks all at once.
